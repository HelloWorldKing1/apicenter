# 低代码集成平台原型 · 说明文档

> 文件：`../低代码集成平台原型.html`（纯前端静态原型，无后端，浏览器直接打开）
> 关联：`低代码集成平台可行性分析.md`（设计文档）、`api演示 demo.html`（早期演示页）

---

## 1. 概述

本原型是一个**低代码 API 集成平台**的可交互演示，核心思想是「**配置驱动**」：用户通过界面配置「源数据源 → 处理步骤 → 目标接口」的集成流程，以及「定时调度」等能力，系统据此执行 API 中转。

定位：作为 ERP 与第三方系统（PARTNER_A / PARTNER_B 等）之间的连接器，只做「连接 + 适配 + 可靠传输」，不承接业务决策。

技术形态：单文件 HTML，内嵌原生 JS + CSS，无外部依赖（Vue/图表库均未使用），所有数据为前端内存模拟。

## 3. 各模块功能说明

### 3.1 首页（BI 仪表盘看板）

- **KPI 卡片**：定时任务数（含启用数）、数据源数、接口数、映射规则集数、函数数、执行次数
- **分布占比条**（纯 CSS 进度条）：任务状态、数据源类型（HTTP/JSON/SQL/Function）、接口协议（JSON/XML）
- **最近执行**：最近 5 条执行日志
- 数据实时聚合自各数据模型，进入首页时刷新（`renderDashboard`）

### 3.2 API 接口管理

三区式布局：
- **顶部**：关键字搜索 + 启用状态筛选（全部/已启用/已停用）
- **左侧**：分类列表（全部/出站/入站/ERP回调，可自定义增删分类）
- **右侧**：接口表格（名称/分类/URL/协议/方法/鉴权/状态/操作），支持分页

接口编辑弹框（**Postman 风格**）：
- **信息行**：接口名称、分类、协议、鉴权类型、API Key、启动开关（Switch）
- **本接口请求**（可折叠）：请求方式（颜色标识）+ URL + Params/Body/Headers 三 Tab
- **接口内容**（可折叠，即「处理方式」）：
  - **转发第三方接口**：第三方请求方式/地址 + 第三方 Params/Body/Headers（Body 支持透传）
  - **接口脚本代码**：脚本代码（JS/Groovy 语言下拉）/ SQL（选数据源）+ 在线调试按钮

接口列表「状态」列用 Switch 开关，可直接启停。

### 3.3 定时任务管理

任务列表列：任务名称 | 调度 | 下次执行 | 源→目标 | 状态 | 操作（编辑/模拟执行/日志/删除），支持分页。

**新建定时任务**（大弹框，分区表单）：
- ① 基本信息：任务名称、启动开关、描述
- ② 调度配置：调度类型（cron 表达式 / 固定间隔）、cron 表达式、间隔秒数、下次执行实时预览
- ③ 流程配置：源数据源（可选 none）、目标接口、处理步骤（算子编排）

**任务编排子视图**（点「编辑」进入）：
- 资源配置：源数据源（可 none）/ 目标接口 / 字段映射规则集
- 调度配置：调度类型 / cron / 间隔 + 下次执行预览
- 流程管线：源节点 → 处理步骤 → 目标节点（点击节点看配置）
- 处理步骤（算子编排）：🔀字段映射 / ⏳过滤 / ⚙️函数处理 / 🧹数据清洗，可增删排序，点击看配置
- 执行预览：模拟执行（源数据 → 映射处理 → 目标数据 + 日志控制台）

### 3.4 数据源管理

四类数据源，**类型 tab 联动配置**：
- **HTTP 接口**：地址 URL、请求方式、鉴权、超时 + Params/Body/Headers 三 Tab（与接口管理一致）
- **JSON 源**：JSON 文本 + ✨ 一键美化按钮
- **SQL 源**：数据库类型（自动带出驱动）、版本、驱动、连接地址、用户名、密码 + 🔌 连接测试 + SQL 查询
- **Function 源**：函数名、脚本

列表支持分页、编辑、删除。

### 3.5 字段映射管理

可复用映射规则集：订单规则集（13 条）、回调规则集（4 条），点击「查看明细」展示规则集字段映射。

### 3.6 函数管理

内置函数库（元数据驱动）：直传、元→分、分→元、时间格式化、手机号脱敏、枚举映射、嵌套写入、明细列表映射、路径取值、默认值、去空格等 11 个函数，展示签名/返回/说明。

### 3.7 日志管理

定时任务执行日志表格（traceId/任务/时间/耗时/状态/操作），预置 8 条模拟日志（成功/失败区分）。每条「详情」按钮 → 日志详情弹框（traceId、任务、执行时间、耗时、状态、调度、源→目标、步骤日志）。

### 3.8 安全设置

- **平台校验**：验签开关、时间戳容差、签名算法
- **IP 白名单/黑名单**：可增删
- **调用方白名单**：AppId / 渠道，可增删

## 4. 数据模型（前端内存）

| 模型 | 关键字段 | 说明 |
|---|---|---|
| `JOBS` | title/desc/enabled/scheduleType/cron/fixedSeconds/srcType/srcLabel/srcUrl/target/targetProto/targetUrl/mappingKey/customMappings/steps | 定时任务 |
| `DATASOURCES` | name/type/url/method/auth/timeout/jsonText/dbType/dbVersion/dbDriver/dbUrl/dbUser/dbPassword/sqlText/functionName/script | 数据源（按 type 用不同字段） |
| `APIS` | name/desc/category/proto/auth/apiKey/method/params/headers/bodyType/bodyRaw/mode/scriptType/scriptLang/scriptCode/sqlDatasourceId/sqlText/thirdMethod/thirdUrl/thirdParams/thirdHeaders/thirdBodyType/thirdBodyRaw/thirdFormParams | 接口（完整契约 + 转发/脚本） |
| `LOGS` | traceId/job/time/ms/status | 执行日志 |
| `MAPPING_SETS` | order/callback 两组规则 | 可复用字段映射规则集 |
| `FUNCTIONS` + `FN_LIST` | 11 个函数元数据 | 函数库 |
| `STEP_TYPES` | mapping/filter/function/cleanse | 处理步骤算子类型 |
| `CLEANSE_TYPES` | 10 种清洗类型 | 数据清洗 |
| `API_CATEGORIES` | outbound/inbound/erp | 接口分类（可增删） |
| `IP_RULES`/`APP_WHITELIST`/`CHANNEL_WHITELIST` | 安全策略 | 白名单/黑名单 |

## 5. 核心交互流程

### 5.1 新建定时任务
```
基本信息（名称/启动/描述）→ 调度配置（cron/间隔，实时预览下次执行）
→ 流程配置（源数据源 + 目标接口 + 处理步骤算子编排，字段映射在「字段映射」算子里）
→ 创建 → 任务列表 + 可进编排界面继续微调
```

### 5.2 编辑定时任务
```
任务列表「编辑」→ 编排子视图：
  资源配置（源/目标/映射规则集）→ 调度配置 → 流程管线 → 处理步骤 → 执行预览
```

### 5.3 新建/编辑接口
```
信息行（名称/分类/协议/鉴权/API Key/启动）→ 本接口请求（方法+URL+Params/Body/Headers）
→ 接口内容（转发第三方 / 脚本代码+在线调试）→ 保存
```

### 5.4 新建/编辑数据源
```
名称 + 类型 tab（HTTP/JSON/SQL/Function）→ 配置区随类型切换 → 保存
```

## 6. 技术实现要点

- **cron 真实计算**：`parseCronField`（支持 `*`/`?`/数字/逗号/范围/步长）+ `cronNextRun`（逐分钟搜索下次执行）+ `cronToDesc`（人类可读）
- **字段映射引擎**：`getPath`/`applyFn`/`setPath`（点号路径取值、函数应用、嵌套目标自动建父节点）
- **算子编排**：`STEP_TYPES` + `currentSteps`，可增删排序，点击切换配置面板
- **分页组件**：`PAGE_SIZE` + `pagerHtml`，任务/数据源/接口三处统一
- **折叠箭头**：`.collapse-head` + `toggleApiSection`
- **Switch 开关**：`.switch` + `.slider`（CSS 滑块）
- **方法颜色标识**：`.method-color.get/post/put/delete/patch`（Postman 风格）
- **模态框**：`.modal-overlay` + `.modal`（接口编辑、新建任务、新建/编辑数据源、日志详情等多个）

## 7. 已知问题与待优化

> 详见最近一次代码审查，以下为待修复项：

1. **保存/发布不持久化字段映射和处理步骤**（`saveFlow` 未写回 `customMappings`/`steps`，编辑后丢失）
2. **`delStep` 用 filter 重新赋值，`currentJob.steps` 不更新**（与 add/move 的引用行为不一致）
3. **切换「字段映射规则集」无提示丢弃手动映射**
4. **手动映射任务在编辑界面仍显示「规则集」下拉**（UI 与实际不符）
5. **模拟执行后首页 KPI/最近执行不刷新**（`runPipeline` 未调 `renderDashboard`）
6. **日志时间格式不一致**（预置 `日期+时间` vs 追加 `HH:MM:SS.mmm`）

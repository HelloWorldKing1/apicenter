# M0-02 · 动态映射语义规范

> 状态：**已评审通过 v1.0（2026-09-02，确认点全部通过）**
> 依据：《API中心设计方案.md》§5.6、《技术架构和实现方案.md》§4.4、《表结构设计.html》表 07 interface_field_mapping
> 对应《开发计划.md》M0 任务二（1 人日）：6 操作 × param 语法、类型注册表边界行为（number→DATE 等定死）、condition 表达式沙箱约束
> 出口：本规范评审通过后，映射引擎实现（M2）按本规范编码；§9 的 24 例矩阵即 M2 单测验收标准。

## 1. 规则模型（与表结构一致）

每条规则：`source`（入站字段，op=default 时可空）+ `op` + `target`（出站字段）+ `param`（操作参数）+ `null_strategy` + `sort_order`。执行顺序 = `sort_order` 升序。校验规则（技术架构 §4.4 已定）：`target` 必填；除 `default` 外 `source` 必填；参数化操作（typeCast/enumMap/condition/aggregate）`param` 必填；`param` 长度 ≤ 500（列宽限制）。

## 2. 字段寻址（定稿 D1）

- `source` / `target` 为**点号路径**（如 `filter.seller_id`、`data.list`），逐级导航；参数名本身含点号即视为嵌套路径（管理面下拉展示字面名，保存时提示「将按嵌套路径解析」）。
- **不支持数组下标寻址**（无 `list[0].name` 语法）；数组元素级转换由 aggregate 覆盖。如需元素级映射，v1.1 扩展路径语法。
- **规则间无可见性（定稿 D2）**：`source` 一律从「入站侧原始模型」取值——后续规则看不到前面规则写入 target 的结果，杜绝顺序依赖与链式副作用。
- **target 写入**：出站侧模型，路径自动创建中间 OBJECT 节点；同名 target 后写覆盖（不合并）。
- **出站组装（定稿 D3）**：`fieldMappings` 为空 → 整体透传（identity，黄金用例即此模式）；非空 → **白名单模式**，仅输出 target 命中字段，未声明的入站字段不进入出站报文。

## 3. null 触发与 null_strategy 四值

- **触发条件**：`source` 路径不存在，或值为 SCALAR NULL，即视为 null。空串、0、false **不是** null。
- 四值语义（定稿 D4）：

| null_strategy | 行为 |
|---|---|
| KEEP 保留原值 | target 写入 null（字段存在、值为 null） |
| NULL 置空 | target 不写（输出中省略该字段）——与 KEEP 的区别是「字段存在与否」 |
| DEFAULT 默认值 | target 写类型零值：STRING→""、INT→0、DECIMAL→0、BOOLEAN→false、OBJECT/ARRAY→null |
| ERROR 报错 | 抛映射错误 → 整单失败，错误码 **40001 字段缺失**（msg 指明缺失的 source） |

- **定稿 D5**：source 为 null 时**不执行 op 本体转换**，直接按 null_strategy 处理（op 差异只体现在非 null 路径）。

## 4. 六操作语义

### 4.1 rename 重命名
`param` 空。source 值（任意节点，含 OBJECT/ARRAY 子树）原样搬移到 target。

### 4.2 typeCast 类型转换
`param` ∈ {STRING, INT, DECIMAL, BOOL, DATE}。转换矩阵（定稿 D6，失败 = 转换异常）：

| 源类型 \ 目标 | STRING | INT | DECIMAL | BOOL | DATE |
|---|---|---|---|---|---|
| STRING | 原样 | trim 后数字串解析（失败 → 转换失败） | 同左（BigDecimal） | `"true"/"1"` → true；`"false"/"0"` → false；其他 → 转换失败 | `yyyy-MM-dd'T'HH:mm:ss[.SSS][XXX]` 或 `yyyy-MM-dd HH:mm:ss` 解析 |
| INT / DECIMAL | 十进制字符串 | INT 截断取整 / 原样 | 原样（BigDecimal） | 0 → false，非 0 → true | epoch：值 > 1e11 视为毫秒，否则视为秒 |
| BOOLEAN | `"true"/"false"` | 1 / 0 | 1 / 0 | 原样 | 不支持 → 转换失败 |
| OBJECT / ARRAY | 序列化为 JSON 字符串 | 不支持 → 转换失败 | 同左 | 不支持 → 转换失败 | 不支持 → 转换失败 |

- **转换失败语义（定稿 D7）**：按该条规则的 null_strategy 处理——KEEP 写源值、NULL 不写、DEFAULT 写零值、ERROR 整单 40001。
- **DATE 输出格式定死**：DATE → STRING = `yyyy-MM-dd'T'HH:mm:ss`；DATE → INT = epoch 秒；DATE → DECIMAL = 支持（同 INT）。
- **数字精度定死**：INT = long 范围内整数；DECIMAL = BigDecimal（JSON 编码 INT 不带小数点、DECIMAL 原样，见 M0-01 D5 平台默认协议参数）。

### 4.3 enumMap 枚举映射
- `param` 语法：`K1→V1, K2→V2`（英文逗号分隔条目，`→` 分隔键值；**值可省略 = 直通**，即 `PENDING` 等价 `PENDING→PENDING`）。
- 键匹配：source 标量 STRING 化后字符串比较；OBJECT/ARRAY source → 转换失败（按 null_strategy）。
- **未命中（定稿 D8）**：原值透传（不触发 null_strategy）——枚举映射只翻译已知值，未知枚举值透传更安全可预期。
- 命中：target 写映射值（字符串）。

### 4.4 default 常量注入
`source` 可空；`param` 即注入的常量值（字符串）。**无条件**将 param 写入 target（不触发 null 判定、不受 null_strategy 影响）。

### 4.5 condition 条件映射
`param` = 布尔表达式（沙箱见 §5）。
- 求值 true → 搬移 source 到 target（此路径下 source 为 null 才触发 null_strategy）。
- 求值 false → 跳过（target 不写，**不触发** null_strategy）。
- 表达式求值异常 → 整单失败 50000（msg 附表达式与原因）。

### 4.6 aggregate 聚合
`param` ∈ `SUM` / `MAX` / `MIN` / `CONCAT[:分隔符]`（CONCAT 可带分隔符，如 `CONCAT:,`，默认无分隔符）。
- source 必须解析为 ARRAY，否则 → 转换失败（按 null_strategy）；空数组视为 null（走 null_strategy）。
- 元素规则（定稿 D9）：SUM 元素须为数值（STRING 数字串自动转，非数值元素 → 转换失败）；MAX/MIN 数值或字符串，同类型比较（混合类型 → 转换失败）；CONCAT 元素 STRING 化后拼接。
- 输出：SUM 元素全 INT 且不溢出 → INT，否则 DECIMAL；MAX/MIN 保持元素类型；CONCAT → STRING。

## 5. condition 表达式沙箱

- **内核选型（定稿 D10）**：**Aviator**（`com.googlecode.aviator:aviator`，需新增依赖；备选 SpEL SimpleEvaluationContext）。理由：Aviator 为纯解释器，无反射、无类加载，天然防注入；语法接近 Java，管理员学习成本低；SpEL 需维护白名单且历史漏洞多，安全成本更高。
- **变量注入规则（定稿 D11）**：入站顶层字段名直接作为变量；字段名含点号（如 `filter.seller_id`）→ 注入别名 = 点号替换为下划线（`filter_seller_id`）。建议管理面提示避免「a.b 与 a_b 并存」的命名冲突。
- **函数白名单（关闭其余全部）**：算数 `+ - * / %`、比较 `== != > >= < <=`、逻辑 `&& || !`、三元 `?:`、括号；字符串 `string.contains / startsWith / endsWith / length / substring`；数值 `math.abs / math.round`。
- **硬限制**：表达式长度 ≤ 500（与 param 列宽对齐）；求值超时 100ms；结果必须 boolean。
- **注入防护用例（M2 单测）**：尝试类加载 / 反射 / 系统调用 / 死循环的表达式必须被拒（拦截或超时）。

## 6. 映射结果与诊断

映射完成后的出站侧模型 = 协议编码的输入；映射结果落 `outbound_request.out_payload`（链引擎 D7 注释，供诊断与重放）。

## 7. 定稿决策记录（ADR）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 点号路径寻址，无数组下标 | 参数名含点（黄金用例 filter.seller_id）需路径语义；数组元素级转换用 aggregate，避免引入复杂路径语法 |
| D2 | 规则间无可见性，source 只读入站侧 | 杜绝顺序依赖；规则可任意重排不影响结果 |
| D3 | 空映射透传 / 非空白名单 | 黄金用例依赖空映射透传；显式配置映射即意图控制出站结构 |
| D4 | NULL=省略字段、KEEP=写 null | 区分「字段缺失」与「字段为 null」，下游感知不同 |
| D5 | null 不执行 op 本体 | 统一 null 路径，op 只定义非 null 行为 |
| D6/D7 | 转换矩阵 + 失败按 null_strategy | 边界行为定死（含 number→DATE），失败有兜底不中断整单 |
| D8 | enumMap 未命中透传 | 翻译已知值即可，未知值透传可预期 |
| D9 | aggregate 仅数组聚合 | 原型 param 为单值下拉，无多字段输入 UI；多字段组合用 condition/多次映射实现 |
| D10 | Aviator 内核 | 安全优先（管理员配置的可执行代码）；无反射天然防注入 |
| D11 | 含点字段名注入下划线别名 | Aviator 变量名不支持点号 |

## 9. 24 例预期输出矩阵（6 操作 × 4 null_strategy）

> M2 单测验收标准。统一样例输入：入站 `{"a": "1", "b": null}`；规则 target 恒为 `t`。「null 输入」统一用 source=b（null）。正常输入按 op 定义（见各行的「正常输入」列）。

| # | op | param | null_strategy | 正常输入 → 预期 t | null 输入（b=null）→ 预期 t |
|---|---|---|---|---|---|
| 1 | rename | — | KEEP | a="1" → t="1" | t=null（字段存在） |
| 2 | rename | — | NULL | a="1" → t="1" | t 不写（字段省略） |
| 3 | rename | — | DEFAULT | a="1" → t="1" | t=""（STRING 零值） |
| 4 | rename | — | ERROR | a="1" → t="1" | 整单失败 40001 |
| 5 | typeCast | INT | KEEP | a="1" → t=1 | t=null |
| 6 | typeCast | INT | NULL | a="1" → t=1 | t 不写 |
| 7 | typeCast | INT | DEFAULT | a="1" → t=1 | t=0（INT 零值） |
| 8 | typeCast | INT | ERROR | a="1" → t=1 | 整单失败 40001 |
| 9 | enumMap | `1→0, 2→1` | KEEP | a="1" → t="0" | t=null |
| 10 | enumMap | `1→0, 2→1` | NULL | a="1" → t="0" | t 不写 |
| 11 | enumMap | `1→0, 2→1` | DEFAULT | a="1" → t="0" | t="" |
| 12 | enumMap | `1→0, 2→1` | ERROR | a="1" → t="0" | 整单失败 40001 |
| 13 | default | `X` | KEEP | —（无条件）→ t="X" | t="X"（null_strategy 不生效） |
| 14 | default | `X` | NULL | → t="X" | t="X" |
| 15 | default | `X` | DEFAULT | → t="X" | t="X" |
| 16 | default | `X` | ERROR | → t="X" | t="X"（不报错） |
| 17 | condition | `a == '1'` | KEEP | true → t="1"（搬移） | false（b=null）→ t 不写 |
| 18 | condition | `a == '1'` | NULL | true → t="1" | false → t 不写 |
| 19 | condition | `a == '1'` | DEFAULT | true → t="1" | false → t 不写 |
| 20 | condition | `a == '1'` | ERROR | true → t="1" | false → t 不写（**不报错**） |
| 21 | aggregate | SUM | KEEP | source=[1,2] → t=3 | t=null |
| 22 | aggregate | SUM | NULL | source=[1,2] → t=3 | t 不写 |
| 23 | aggregate | SUM | DEFAULT | source=[1,2] → t=3 | t=0 |
| 24 | aggregate | SUM | ERROR | source=[1,2] → t=3 | 整单失败 40001 |

> 补充断言（矩阵外的单测）：enumMap 未命中透传（source="9" → t="9"，任一 null_strategy）；typeCast 转换失败按 null_strategy（source="abc" 转 INT：KEEP→t="abc" / ERROR→40001）；aggregate 非数组 source 按 null_strategy；condition 表达式注入用例（§5）与超时用例；DATE 边界（epoch 秒/毫秒、ISO 解析、DATE→STRING 格式）。

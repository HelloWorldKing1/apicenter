分组下拉 · 内联创建

新建接口时，在已选应用之下直接创建分组：分组下拉底部提供「＋ 新建分组」动作，点击后原位变形为迷你表单， 回车即创建并自动选中。全程不离开接口表单、不丢已填内容。以下 demo 可真实操作（前端模拟接口）。

状态流签名：底部动作区原位变形

列表态选项列表 + 底部「＋ 新建分组」动作行，常驻可见（不藏在悬停后）
输入态动作行原位变形为迷你表单：上下文行「创建到 应用名 之下」+ 输入框（自动聚焦）+ 创建/取消，下拉保持打开
成功新选项插入列表并选中 → 下拉收起 → 轻提示「已创建分组「xx」」
失败空名称 / 应用内重名：输入框下方内联报错，红框，不关下拉不丢输入

行为规格

确认Enter 或点「创建」；防重复提交（请求中按钮置 loading）
取消Esc 或「取消」或点击下拉外区域：静默放弃输入，回到列表态
排序sortOrder 取默认 0（与分组页新建一致，可在分组页调整）
重名预检先本地比对 groupOptions（即时反馈），后端唯一约束兜底
应用约束未选应用时分组下拉禁用（现状），入口自然不可达；切换应用清空已选分组与输入态
可访问性动作行可 Tab 聚焦；aria-label「新建分组」；reduced-motion 下关闭形变动画

实现落点

组件el-select #footer 插槽（EP ≥ 2.4.3，本项目 2.8.0 ✓），无需 hack popper DOM
改动文件Interfaces.vue 仅基本信息区 + 少量 state（creating / name / error / loading）
接口复用 POST /api/admin/groups（{appId, name, sortOrder: 0}），无后端改动；创建成功后刷新本应用的 groupOptions
文案动作「＋ 新建分组」→ 上下文「创建到 xx 之下」→ 占位「输入分组名称，回车创建」→ 错误「该应用下已存在同名分组」→ 提示「已创建分组「xx」」，与分组页新建共用词汇

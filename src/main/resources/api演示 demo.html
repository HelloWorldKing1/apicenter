      3.1 字段映射 @HttpExchange + Jackson 注解 + MapStruct

      同一业务对象 OrderDto 映射为 PARTNER_A（JSON）与 PARTNER_B（XML）两种第三方格式。悬停行查看对应字段。
      语义ERP 字段PARTNER_A JSON 键PARTNER_B XML 键转换规则
      订单号orderIdorderNo<OrderNo>命名差异（camel ↔ Pascal）
      业务类型orderTypeorderType<OrderType>直传
      状态orderStatusorderStatus<Status>值映射 NEW→1 / PAID→2 / SHIPPED→3
      总金额totalAmount（元）totalAmountCent（分）<TotalAmount>（分）元 ×100 → 分（BigDecimal→long）
      币种currencycurrency<Currency>直传
      买家buyerName + buyerPhonebuyer.name / buyer.mobile<Buyer><Name> / <Phone>平铺 → 嵌套聚合
      创建时间createdTimecreatedAt（ISO-8601）<CreatedTime>（yyyyMMddHHmmss）时间格式差异
      明细items[]items[]<Item> 平铺（无外层包裹）嵌套列表；金额同 ×100
      收货地址shippingAddressreceiver<Receiver>字段重命名 + 嵌套
      备注remarknote<Remark>命名差异

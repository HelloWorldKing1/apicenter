API 中心 · 表结构设计

依据《API中心设计方案.md》《API中心原型.html》整理 · 共 15 张表：配置类 10 张 + 运行类 5 张 · 生产 MySQL 8.0 InnoDB

设计目标：完整承载「应用（供应商）→ 分组 → 接口」配置模型、适配器定义与绑定、两条链路的状态机载体与可观测数据。
三条主线：配置类表（管理面读写，低频高价值）、运行类表（执行面高频追加，只按状态/时间扫描）、快照表（版本化/灰度）。统一内部模型与报文内容一律以 CLOB 承载，不在关系列展开。

01

应用（供应商）

app
应用 = 平台对接的一方供应商（第三方上游）。持有出站签名凭证与回调验签凭证两类；IP 黑白名单、配额限流在此表统一承载。
字段类型约束说明
app_idVARCHAR(32)PK全局唯一应用标识（如 TENCENT-CLOUD）
nameVARCHAR(64)NOT NULL应用名称
contactVARCHAR(64)联系人
auth_adapter_idVARCHAR(16)FK NULL出站供应商签名适配器（FK → adapter.id，NULL = 无鉴权）
callback_auth_adapter_idVARCHAR(16)FK NULL回调验签适配器（FK → adapter.id，NULL = 无鉴权），仅对入站回调接口生效
outbound_secretVARCHAR(255)出站凭证（appSecret / secretId+secretKey / token），加密存储，永不回显明文
callback_secretVARCHAR(255)回调验签凭证（回调 HMAC secret / 云厂商回调 token），加密存储，独立于出站凭证
default_message_adapter_idVARCHAR(16)FK NULL默认报文适配器（FK → adapter.id，NULL = 平台默认）；接口级绑定可覆盖
base_urlVARCHAR(255)服务地址（供应商 API 根地址，出站接口的上游路径拼于此）
ip_whitelistVARCHAR(500)来源 IP 白名单（英文逗号分隔，空 = 不限制）
ip_blacklistVARCHAR(500)来源 IP 黑名单
qps_limitINTQPS 限流（空/0 = 不限）
daily_quotaBIGINT日调用量上限
statusVARCHAR(16)NOT NULL生命周期：DRAFT 草稿 / ENABLED 启用 / DISABLED 停用 / CANCELLED 注销；停用拒绝其请求，注销后回收 appId
descVARCHAR(500)描述
created_at / updated_atDATETIMENOT NULL创建 / 更新时间
索引：PK(app_id)，INDEX(auth_adapter_id)，INDEX(callback_auth_adapter_id)，INDEX(default_message_adapter_id)
凭证轮换（新旧短暂并存）由 outbound_secret / callback_secret 的加解密层 + 双值过渡期实现，表结构不展开历史。
02

分组

app_group
应用下的组织单元，纯归类/展示用，不承载配置。层级：应用 → 分组 → 接口。
字段类型约束说明
idBIGINTPK 自增分组主键
app_idVARCHAR(32)FK → app.app_id所属应用
nameVARCHAR(64)NOT NULL分组名称（应用内唯一）
sort_orderINTDEFAULT 0排序
created_atDATETIMENOT NULL创建时间
索引：PK(id)，UNIQUE(app_id, name)
03

接口定义

interface
接口 = 平台对外暴露 / 代理的一个 API 定义。类型区分出站中转与入站回调；目标地址随类型互斥（出站 = 上游路径，入站 = 回调地址）。参数、映射、响应/ack 字段、适配器绑定分别落在子表。
字段类型约束说明
idBIGINTPK 自增主键
codeVARCHAR(16)UNIQUE NOT NULL接口标识（如 IF001），对外展示与引用
nameVARCHAR(64)NOT NULL接口名称
if_typeVARCHAR(16)NOT NULLOUTBOUND 出站中转 / INBOUND 入站回调
methodVARCHAR(8)NOT NULLHTTP 方法（POST / GET / PUT / DELETE）
pathVARCHAR(255)NOT NULL平台侧路径（如 /api/orders、/callback/{appId}/instance-state）
protocol_inVARCHAR(8)DEFAULT 'JSON'入站协议（来源 → 平台）：JSON / XML
protocol_outVARCHAR(8)DEFAULT 'JSON'出站协议（平台 → 目标）：JSON / XML
app_idVARCHAR(32)FK NOT NULL归属应用（供应商，既是归属也是上游）
group_idBIGINTFK NOT NULL归属分组（须属于所选应用）
upstream_pathVARCHAR(255)出站上游路径（相对路径，拼 app.base_url；仅 OUTBOUND）
callback_urlVARCHAR(255)入站回调地址（送达目标 URL；仅 INBOUND，必填）
statusVARCHAR(16)DEFAULT 'DRAFT'DRAFT 草稿 / PUBLISHED 发布 / OFFLINE 下线；下线后停止路由
versionINTDEFAULT 1配置版本（变更生成新版本，见 interface_snapshot）
timeout_msINTDEFAULT 3000读超时（出站 = 调上游超时；入站 = 回调地址调用超时）
max_retriesINTDEFAULT 4最大重试次数
descVARCHAR(500)描述
created_at / updated_atDATETIMENOT NULL创建 / 更新时间
索引：PK(id)，UNIQUE(code)，UNIQUE(path)（平台侧路径路由唯一），INDEX(app_id)，INDEX(status)
类型互斥约束（应用层校验）：OUTBOUND 必填 upstream_path、禁用 callback_url 与 ack 字段；INBOUND 必填 callback_url、出站侧（interface_param side=OUT）为送达报文必填。
04

接口配置快照

interface_snapshot
版本化支撑：接口配置变更时整体快照，支持回滚与灰度发布。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK → interface.id所属接口
versionINTNOT NULL版本号
config_jsonCLOBNOT NULL整接口定义快照（参数 / Body / 字段映射 / 响应·ack / 适配器绑定）
change_noteVARCHAR(255)变更说明
created_atDATETIMENOT NULL快照时间
索引：PK(id)，UNIQUE(interface_id, version)
05

请求参数

interface_param
两侧请求参数：入站侧（来源 → 平台）与出站侧（平台 → 目标）。入站回调接口的「出站侧」= 送达报文（必填）。字段映射的 source/target 从此表两侧取值。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK NOT NULL所属接口
sideVARCHAR(8)NOT NULLIN 入站侧 / OUT 出站侧
nameVARCHAR(64)NOT NULL参数名（同侧唯一）
typeVARCHAR(16)DEFAULT 'string'string / number / boolean / object / array
requiredTINYINT(1)DEFAULT 0是否必填
sampleVARCHAR(255)示例值
sort_orderINTDEFAULT 0排序
索引：PK(id)，UNIQUE(interface_id, side, name)
06

请求体

interface_body
每侧一个 Body 配置：类型 + 原始模板 / form 字段。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK NOT NULL所属接口
sideVARCHAR(8)NOT NULLIN / OUT（与 interface_param.side 对应）
body_typeVARCHAR(32)DEFAULT 'none'none / form-data / x-www-form-urlencoded / json / xml
rawCLOBBody 原始模板（json / xml 时使用）
formCLOBform-data 字段列表（JSON 数组）
索引：PK(id)，UNIQUE(interface_id, side)
07

字段映射

interface_field_mapping
接口级字段映射规则（入站 → 出站）。规则为运行时配置，由映射引擎按 op 解释执行；param 承载参数化操作的值。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK NOT NULL所属接口
sourceVARCHAR(64)入站字段（来自 interface_param side=IN；op=default 常量注入时可空）
opVARCHAR(16)NOT NULLrename / typeCast / enumMap / default / condition / aggregate
targetVARCHAR(64)NOT NULL出站字段（来自 interface_param side=OUT）
paramVARCHAR(500)操作参数：枚举映射表（PENDING→0, DONE→1）/ 默认值 / 条件表达式 / 聚合方式 / 目标类型；参数化操作必填
null_strategyVARCHAR(16)DEFAULT 'KEEP'KEEP 保留原值 / NULL 置空 / DEFAULT 默认值 / ERROR 报错
sort_orderINTDEFAULT 0执行顺序
索引：PK(id)，INDEX(interface_id)
08

响应 / ack 字段

interface_field_def
出站接口 = 出站响应字段（出站方返回的字段列表，kind=RESP）；入站接口 = ack 回执字段（平台回供应商的回执结构，固定 code/message，kind=ACK）。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK NOT NULL所属接口
kindVARCHAR(8)NOT NULLRESP 出站响应字段（仅 OUTBOUND）/ ACK ack 回执字段（仅 INBOUND）
nameVARCHAR(64)NOT NULL字段名
typeVARCHAR(16)DEFAULT 'string'字段类型
descVARCHAR(255)字段说明
sort_orderINTDEFAULT 0排序
索引：PK(id)，UNIQUE(interface_id, kind, name)
09

适配器定义

adapter
三类适配器（鉴权 / 协议 / 报文）的全局定义。无状态、配置驱动；params 为按 impl 元数据 schema 的 JSON。字段映射为接口级配置，不作为适配器类型。
字段类型约束说明
idVARCHAR(16)PK适配器标识（如 ADP-001）
nameVARCHAR(64)NOT NULL适配器名称（展示用，建议唯一；绑定一律按 id 引用）
typeVARCHAR(16)NOT NULLauth 鉴权 / protocol 协议 / message 报文
implVARCHAR(64)NOT NULL实现类：HmacAuthAdapter / CloudSignatureAdapter / CloudCallbackSignatureAdapter / JsonProtocolAdapter / XmlProtocolAdapter / EnvelopeMessageAdapter / HeaderMappingAdapter 等
enabledTINYINT(1)DEFAULT 1启用 / 停用
versionVARCHAR(16)DEFAULT '1.0'版本（用于版本化 / 灰度）
paramsCLOB参数 JSON（按 impl 元数据 schema，如 HMAC 的 signatureAlgorithm/signatureHeader/timestampToleranceSeconds/replayProtection）；凭证类参数不落此处，统一存 app
created_at / updated_atDATETIMENOT NULL创建 / 更新时间
索引：PK(id)，INDEX(type)
10

接口-适配器绑定

interface_adapter_binding
接口可绑定的适配器角色：MESSAGE 报文、AUTH 供应商签名（仅出站接口有效）、CALLBACK_AUTH 回调验签（仅入站接口有效）。adapter_id 为空 = 继承应用默认：MESSAGE → app.default_message_adapter_id（空则平台默认）；AUTH / CALLBACK_AUTH → app.auth_adapter_id / app.callback_auth_adapter_id。协议适配器由 interface.protocol_in / protocol_out 按协议自动推导，不进本表。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK NOT NULL所属接口
roleVARCHAR(16)NOT NULLMESSAGE / AUTH / CALLBACK_AUTH
adapter_idVARCHAR(16)FK NULL绑定的适配器；NULL = 继承应用默认
versionVARCHAR(16)指定适配器版本（灰度切换；空 = 用适配器当前启用版本）
索引：PK(id)，UNIQUE(interface_id, role)
11

出站请求（Flow A 状态机载体）

outbound_request
出站 outbox：每次调用一行，status 即状态机载体。补偿 worker 按 (status, next_retry_at) 扫描；UNKNOWN 记录进对账。重放安全依赖上游对业务键（biz_id）幂等。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK NOT NULL所属接口
app_idVARCHAR(32)NOT NULL供应商应用
biz_idVARCHAR(64)NOT NULL业务键（请求携带稳定 biz_id，上游据此去重）
in_payloadCLOB入站原始报文（统一内部模型序列化）
out_payloadCLOB映射后出站报文（诊断 / 重放用）
resp_payloadCLOB供应商响应
statusVARCHAR(32)NOT NULLINIT / MAPPING / SENDING / RETRYING / COMPENSATING / SUCCESS / DEAD_LETTER / UNKNOWN
attempt_countINTDEFAULT 0累计尝试次数（首送 + 短重试 + 补偿重试）
max_attemptsINTDEFAULT 5补偿最大次数（超限转死信；短重试上限另取 interface.max_retries）
next_retry_atDATETIME下次重试 / 补偿时间（worker 扫描依据）
error_codeVARCHAR(32)错误码（50201 上游 5xx / 50401 超时等）
trace_idVARCHAR(32)全链路 traceId
created_at / updated_atDATETIMENOT NULL创建 / 状态更新时间
索引：PK(id)，INDEX(status, next_retry_at)（补偿/对账扫描），INDEX(app_id, biz_id)（定位），INDEX(trace_id)
12

入站送达（Flow B 状态机载体）

inbound_delivery
供应商回调经映射后的送达记录。ack 为回执：收到回调即回供应商（与送达结果解耦）；送达失败转 PENDING 由补偿 worker 重送。
字段类型约束说明
idBIGINTPK 自增主键
interface_idBIGINTFK NOT NULL所属入站回调接口
app_idVARCHAR(32)NOT NULL供应商应用（冗余自 interface，便于按应用统计 / 扫描）
callback_event_idVARCHAR(64)供应商回调事件标识（审计 / 追溯）
payloadCLOB送达报文（出站侧 = 回调字段经字段映射后的结果）
callback_url_snapshotVARCHAR(255)送达回调地址快照（重送按快照地址执行，不随接口改址漂移）
delivery_statusVARCHAR(16)NOT NULLRECEIVED / ACKED（送达成功）/ PENDING（待重送）/ DEAD_LETTER（重送耗尽）
attempt_countINTDEFAULT 0已尝试送达次数
max_attemptsINTDEFAULT 5重送最大次数（超限转死信）
next_retry_atDATETIME下次重送时间（补偿 worker 扫描依据）
ack_to_partnerVARCHAR(16)回执状态（收到即回 ACKED，与送达结果解耦）
trace_idVARCHAR(32)全链路 traceId
created_at / updated_atDATETIMENOT NULL创建 / 状态更新时间
索引：PK(id)，INDEX(delivery_status, next_retry_at)（补偿扫描），INDEX(trace_id)
13

死信

dead_letter
出站 4xx / 重试耗尽 / 补偿耗尽 / 入站重送耗尽落此表，人工或管理端点查看与重放（重放 = 重新入队）。
字段类型约束说明
idBIGINTPK 自增主键
biz_typeVARCHAR(16)NOT NULLOUTBOUND / INBOUND
ref_idBIGINT关联 outbound_request.id 或 inbound_delivery.id
reasonVARCHAR(2000)死因（业务错误码 / 重试耗尽说明）
payloadCLOB报文快照（重放依据）
statusVARCHAR(16)DEFAULT 'PENDING'PENDING 待处理 / HANDLED 已处理（重放后置位）
handled_atDATETIME处理时间
created_atDATETIMENOT NULL创建时间
索引：PK(id)，INDEX(biz_type, status)

调用日志

call_log
AOP 拦截记录每次调用的请求 / 响应 / 耗时 / 结果；敏感字段（手机号、密钥、Header 敏感值）落库前脱敏。
字段类型约束说明
idBIGINTPK 自增主键
trace_idVARCHAR(32)traceId（贯穿全链路）
span_idVARCHAR(32)span 标识（OpenTelemetry）
directionVARCHAR(8)NOT NULLIN 入站（调用方→平台 / 供应商回调→平台）/ OUT 出站（平台→供应商 / 平台→回调地址）
interface_idBIGINT关联接口
app_idVARCHAR(32)关联应用（供应商）
urlVARCHAR(255)目标 URL
methodVARCHAR(8)HTTP 方法
status_codeINT状态码
latency_msBIGINT耗时（毫秒）
req_headersVARCHAR(2000)请求头（已脱敏）
req_bodyCLOB请求体
resp_bodyCLOB响应体
created_atDATETIMENOT NULL记录时间
索引：PK(id)，INDEX(trace_id)，INDEX(created_at)，INDEX(interface_id)
日志为高频追加表：异步批量写入；按保留期归档 / 清理。

enabledTINYINT(1)DEFAULT 1启用 / 停用
created_at / updated_atDATETIMENOT NULL创建 / 更新时间
索引：PK(id)，INDEX(enabled)

附录 C · 设计约定

约定内容
命名小写下划线；业务标识沿用字符串码（app_id、interface.code、adapter.id），关联表用自增 BIGINT 外键
审计字段配置类表 created_at / updated_at；运行类 append-only（状态流转表带 updated_at）
凭证凭证一律存 app.outbound_secret / callback_secret（加密存储、遮显回显、日志脱敏，永不落明文）；adapter.params 只存非凭证参数（算法 / 头名 / 容差等），避免双写
大字段报文、参数 JSON、params 均用 CLOB / TEXT，不在关系列展开

## 2. 调用约定

```bash
# 平台对外路径 = interface.path（全局唯一路由键）
POST http://<host>:8080/pm/t1-jj
Content-Type: application/json        # 对应 protocol_in（XML 组合时为 application/xml）
X-Trace-Id: <可选，链路 ID；平台会透传给供应商>
X-Biz-Id:   <可选，业务键；供应商幂等依赖>

# 平台对外响应恒为 JSON 统一信封（与入站协议无关）
{"code":0,"msg":"ok","data":{…}}       # HTTP 状态码 = 业务码 / 100
```

**平台侧统一响应与错误码（本次实测涉及）**

| 业务码 | HTTP | 含义 | 本次实测 |
|---|---|---|---|
| 0 | 200 | 成功 | T1 / T2 / T3 / A1 |
| 50201 | 502 | 供应商 4xx（非 429）→ 转死信、不重试 | T4（供应商 404 model_not_found） |
| 40002 | 400 | 报文错误（格式非法 / 超 1MB / XML 混合内容 / 嵌套超限） | 未触发 |
| 50401 | 504 | 供应商读超时 → UNKNOWN 对账 | 未触发（T2/T3 已把读超时提到 15000ms） |

> 说明：本组件**不鉴权调用方**（Flow A 的 INBOUND_AUTH 为 Noop 占位，调用方鉴权属平台统一能力，见《入站鉴权设计方案.md》）；入站回调接口才有 CALLBACK_AUTH 验签。

## 3. 格式转换总览（六阶段链）

```
调用方 ──原始字节──► ① 入站鉴权 ─► ② 协议解码 ─► ③ 报文适配 ─► ④ 字段映射 ─► ⑤ 协议编码 ─► ⑥ 出站鉴权 ─► 供应商
         (protocol_in)   (Noop/验签)   (→ 统一模型)   (MESSAGE)     (接口规则)    (protocol_out)  (注入凭证)
供应商 ──原始字节──► 响应解码(protocol_out) ─► 业务成败判定 ─► RESP 白名单过滤 ─► 统一信封 {code,msg,data} ──► 调用方
```

**四种组合的差异只落在两个开关**：`protocol_in`（怎么解调用方的报文）与 `protocol_out`（怎么编给供应商的报文、以及怎么解供应商的响应）。报文适配 / 字段映射 / 鉴权与协议无关。

| 用例 | 组合 | protocol_in 解码 | protocol_out 编码 | 响应解码 | 报文是否真实发出 |
|---|---|---|---|---|---|
| T1 | JSON→JSON | JSON → 对象 | 对象 → JSON（紧凑） | JSON | ✅ 是（POST 带 body） |
| T2 | JSON→XML | JSON → 对象 | 对象 → `<request>…` XML | XML | ⚠️ 否（GET 不带 body，仅完成编码） |
| T3 | XML→XML | XML 根 → 对象 | 对象 → `<request>…` XML | XML | ⚠️ 否（同上） |
| T4 | XML→JSON | XML 根 → 对象 | 对象 → JSON（紧凑） | JSON | ✅ 是（POST 带 body） |
| A1 | JSON→XML（辅助） | JSON → 对象 | 对象 → `<request>…` XML | （响应为 JSON，解码失败 → 空） | ✅ 是（POST，httpbin 回显原文） |

## 5. 注意事项与边界（实测得出）

| # | 事项 | 说明 |
|---|---|---|
| 1 | **GET/DELETE 不携带请求体** | `UpstreamInvoker` 对 GET/DELETE 不调 `.body()`；`out_payload` 对 GET/DELETE 也恒为空（`outboundBodyText` 返回 null）。即「XML 已编码」不等于「XML 已发送」——需要供应商收到 body 的场景必须配 **POST** |
| 2 | XML 出站根元素写死 `<request>` | 无法自定义根元素 / 命名空间 ⇒ SOAP 类真实供应商调不通（设计边界） |
| 3 | 读超时须按公网供应商调大 | USGS 实测 1.8~4.3s；历史 3000ms 配置出现过 3008ms 超时误判。建议 ≥10000ms |
| 4 | 响应协议配错不会报错 | 响应解码失败按空对象（宽松）⇒ 表现「code=0 + data={}」；排查时先比对调用日志 OUT 条 respBody 原文 |
| 5 | XML 属性默认不映射 | `attrVsElement=ELEMENT`；`<link href="…"/>` 这类纯属性元素解出为 `null` |
| 6 | RESP 声明为空 = 不过滤 | 需要收敛响应字段时必须显式声明（T1 8→4、T2 7→3 即白名单效果） |
| 7 | 供应商 4xx 语义 | 4xx（非 429）⇒ 死信 + 50201 且**不重试**；本次 T4 的 `retryable=false` 与平台行为一致 |

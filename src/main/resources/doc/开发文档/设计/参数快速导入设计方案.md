# 请求参数快速导入设计方案（接口管理 → 请求参数）

> 版本：v1.0（2026-09-12 评审通过并落地）｜范围：`frontend/src/views/Interfaces.vue` 请求参数区（IN / OUT 两侧 Params 面板）
> **拍板结果（D1–D6 全部按推荐）**：D1 数组元素路径 `list[0].id`｜D2 默认全部必填（`null` / 空容器除外）+「仅顶层必填」可选｜D3 覆盖同名并追加（+ 一次撤销快照）｜D4 条数上限 200、深度上限 6｜D5 本期 JSON + form-urlencoded（XML 延后）｜D6 提供撤销导入
> **实现状态**：已落地（内核 `utils/paramImport.mjs` + 弹窗 `components/ParamImportDialog.vue` + Interfaces 接线）；单测 14 例、组件 SSR 冒烟 1 例，`npm test` 全绿。

## 1. 目标与非目标

**目标**：把一段真实请求 JSON 粘进输入框，一键推断出参数表（参数名 / 类型 / 必填 / 示例值），支持格式校验与美化。

**非目标**：不自动生成字段映射规则、不改写请求体模板、不静默覆盖用户已手改的行（除「覆盖同名」选项）。

## 2. 现状约束（代码事实）

| # | 事实 | 位置 |
|---|---|---|
| 1 | 参数模型 `ParamDto(side, name, type, required, sample, sortOrder)`，`side ∈ {IN, OUT}` | `dto/InterfaceDtos.java` |
| 2 | 前端类型下拉 5 值：`string/number/boolean/object/array`；后端不限值域（null → string） | `ParamTable.vue`、`InterfaceService` |
| 3 | 参数名支持点号路径（`filter.seller_id`） | `ParamTable.vue` placeholder |
| 4 | 入站接口必须含 OUT 侧参数；出站接口开启透传时 OUT 侧参数被清空 | `InterfaceService`、`Interfaces.vue` |
| 5 | 后端不校验参数名空值 / 重复 / 字符集 → 语义校验必须在前端 | 仓库 grep 无相关校验 |

## 3. 交互

入口：每个 side block 的 Params 面板工具条（`⇪ 快速导入参数`）+ 导入后的 `撤销导入`。

```
① 粘贴 JSON   [从本侧请求体带入] [美化] [清空]
  ┌ textarea（防抖 300ms 校验） ────────────────────────────┐
  ✓ 格式合法 · 识别 12 个字段 · 最大深度 4                   │
  ✗ 第 3 行 8 列：括号不匹配：期望 } 但遇到 ]   [定位]        │
② 导入选项：已存在参数 [覆盖同名并追加|清空后导入] / 必填策略 [全部必填|仅顶层必填]
           嵌套展开 [开] / 数组取样 [开]
③ 预览表（前 50 条）：参数名 / 类型 / 必填 / 示例值
                          [取消] [导入 12 条]
```

## 4. 映射规则

| JSON 值 | 生成行 | type | 示例值 | 必填 |
|---|---|---|---|---|
| 字符串 / 数字 / 布尔 | 父键 | `string` / `number` / `boolean` | **token 原始切片** | ✓ |
| `null` | 父键 | `string`（保守） | 空 | ✗ |
| 对象 | 容器行 + 递归子键（`a.b`） | `object` | 空白折叠后的 JSON 片段（≤120 字符） | ✓ |
| 数组 | 容器行 + 首个元素样本（`list[0].x`） | `array` | `[N 项]` | ✓ |
| 空对象 / 空数组 | 保留行 | `object` / `array` | `{}` / `[]` | ✗ |
| 顶层数组 | 直接按 `[0]` 展开 | — | — | ✓ |
| 顶层标量 | **报错**（不硬猜） | — | — | — |

- **路径转义**：键名含 `.`/`[`/`]`/空格 → `["原始键"]`；空键名 → 整棵子树跳过并提示。
- **保真契约**：示例值取 **token 原始切片**，不取 `JSON.parse` 的值 —— 否则 19 位数字会被改写（`7494312521977267257` → `…267000`）、`1.10` → `1.1`、`1e3` → `1000`（与《接口监控设计方案》§8 同一条原则）。`JSON.parse` 只用于语法校验。
- **form-urlencoded（D5 顺带）**：`k=v&…` → 每对一条，值做 `decodeURIComponent`（失败保留原值），类型按值文本推断。

## 5. 校验与限额

| 级别 | 检查 | 表现 |
|---|---|---|
| 语法 | 结构扫描（字符串/括号栈）优先，V8 消息正则兜底 | 行/列 + 原因 + 出错行片段 + 「定位」；未闭合提示「内容可能被截断」 |
| 完整性 | 截断后缀 `...[truncated]` / 结构未闭合 | 结构完整 → 标注截断后允许导入；未闭合 → 报错不猜数据 |
| 语义 | 重复键（后者生效）、空键名、特殊键名、条数 >200、深度 >6 | 预览期 warning，不阻断（超限截断并计数） |

## 6. 实现

| 层 | 文件 | 说明 |
|---|---|---|
| 内核 | `frontend/src/utils/paramImport.mjs` | `extractParams(text, options)` → `{ok, error, truncated, format, params[], warnings[], stats}`；`scanStructureIssue` / `locateJsonError` 负责定位；令牌用 `tokenizeJson`（`payload.mjs`）后**按字符拆开标点**，以逐括号匹配容器 |
| 弹窗 | `frontend/src/components/ParamImportDialog.vue` | 粘贴区 + 校验状态 + 选项 + 预览表 + 美化（JSON 走 `formatJson` 扫描缩进、form 走 `formatForm`）+ 「定位」按钮（textarea 选区） |
| 接线 | `frontend/src/views/Interfaces.vue` | 工具条按钮（每侧各一）+ 弹窗挂载 + `applyImport`（覆盖同名并追加 / 清空后导入，写回真实数组并重排 `sortOrder`）+ `importUndo` 一次撤销快照 |
| 测试 | `src/utils/paramImport.test.mjs`（14 例）+ `test/ssr-smoke.mjs`（1 例） | 覆盖嵌套/数组取样/保真/空值/顶层数组/选项/限额/重复键/特殊键名/form/语法错误/截断/顶层标量 |

## 7. 验收

1. 粘贴 `{"filter":{"seller_id":7494312521977267257,"orderby":[{"field":"units_sold"}]},"page":1}` → 预览出现 `filter` / `filter.seller_id`（示例值 19 位原样）/ `filter.orderby`（`[1 项]`）/ `filter.orderby[0].field` / `page`；
2. 非法 JSON（少括号）→ 红字给出行列与原因，导入按钮禁用；
3. 已有同名参数时选「覆盖同名并追加」→ 同名行被更新，其余追加；「撤销导入」可回退；
4. 出站接口开透传时 OUT 侧不出现导入按钮（该侧参数本就会被清空）；
5. `cd frontend && npm test` 全绿（单测 40 例 + SSR 冒烟 11 例）。

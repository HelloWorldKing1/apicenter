## 4. S4 入站鉴权 v1.2（**核心**，约 20 分钟）

> 深挖版见 `入站鉴权手动验收测试方案.md` v3.0。

### S4.0 先把闸门打开（**唯一的配置项改动**）

`src/main/resources/application.yaml` → `app.api-center.client-auth.mode: "OFF"` 改为 **`"ENFORCED"`**（**记得带引号**，裸 `OFF` 会被 YAML 解析成布尔 false）→ **重启后端**。

- [x] 重启后，**不带任何鉴权头**直接调 `/ma/out` ⇒ **401**（body 含 `40107`）

3. 选 `ADP-401` → 点「保存设置」；
4. 看「影响面」提示与卡片右上「最后修改：<你的账号> · <时间>」。

- [x] 下拉里**只有**入站验签实现（不出现报文/协议/出站签名适配器）

- [x] **反证**：把接口专属池那把**吊销** → 再用平台池密钥调 ⇒ **200**（说明前一步的拒绝确实来自"短路"）

### S4.6 单独吊销 + 备注（"只吊销某一个调用方"）

1. 平台共享池里发两把（备注 `A 公司` / `B 公司`）并都**激活**；两把各调一次 ⇒ 都 200；

## 附 A：错误码速查（验收对照）

| 码 | 含义 | 出现场景 |
|---|---|---|
| `40001` | 参数/校验失败 | 保存非法配置、链路失败、云签名缺 AK/SK |
| `40002` | 报文格式非法 | 入站报文超限 / 解析失败 |
| `40100` | 凭证/签名不匹配 | 密钥错、签名错、**缺少凭证头** |
| `40101` | 时间戳超容差 | HMAC 时间戳过期 |
| `40102` | 应用停用 | 供应商被停用 |
| `40103` | 来源 IP 被拒 | 黑名单命中 / 白名单未命中；仅 IP 名单方式未配名单 |
| `40104` | 未登录 / 令牌无效 | 管理面缺令牌、令牌过期 |
| `40105` `40106` | 账号口令错 / 已锁定 | 登录 |
| `40107` | 调用方未知/已停用 | **`require_client_id=1` 档**下缺 / 未知 `X-Client-Id` |
| `40108` | 未配置鉴权方式 / 无可用凭证 | 三级回退全空；平台池为空 |
| `40301` | 注册被关闭 | 账号注册 |
| `40302` `40303` `40304` `40305` | 只读角色写 / 无账号管理权 / **仅 OWNER** / **无入站鉴权管理权** | 权限矩阵 |
| `40401` `40402` `40403` `40405` | 接口 / 应用 / 快照 / 账号不存在 | —— |
| `40901` | 用户名已存在 | 注册 |
| `42901` `42902` | QPS / 日配额超限 | 接入层防护（**不落运行表**） |
| `50201` `50203` | 供应商 5xx / **SOAP 客户端类 Fault** | 50203 ⇒ 死信且**不重试不计熔断** |
| `50401` | 超时 / 结果未知 | ⇒ UNKNOWN ⇒ 对账 |

## 附 C：出问题时的取证四步

1. **先看「接口监控 → 调用日志」**（按 bizId / traceId）：IN 一行的 4xx/5xx 与 body 说明**平台看到/发出了什么**；
2. **再看 `http://localhost:18080/__admin/requests`**：确认**供应商到底收到了什么**（头 + 体）——区分"平台没发"与"供应商没收到"；
3. **看「状态机与对账」**：状态与状态链告诉我们**平台自己的判断**（是否重试/补偿/死信/UNKNOWN）；
4. **最后看审计「接入鉴权」**：鉴权类问题（401xx）只看这里 —— 里面有主体、IP、方式、**命中的凭证备注/指纹**、错误码与原因。

## 附 D：常见误判（**别当成缺陷**）

| 现象 | 是缺陷吗 | 说明 |
|---|---|---|
| 改了 `mode` 但行为没变 | ❌ | **启动期**属性，必须重启（`mode` 刻意如此：应急总开关要"有意动作"） |
| 保存平台设置后**没重启**也生效了 | ❌ | 平台设置与凭证**是**运行期的（落库 + 缓存失效）；只有 `mode` 要重启 |
| 接口专属池配了，平台池密钥却仍能调通 | ✅ **是缺陷** | 短路语义被实现成并集（应只看接口池那一级） |
| 令牌步骤每次调用都换 token | ✅ **是缺陷** | 缓存没生效（检查是否命中、`ttlFallbackSeconds` 是否 0） |
| token 明文出现在调用日志里 | ✅ **是缺陷** | 脱敏失效（应为 `SECR****OKEN` 形态） |
| 报 `40108` 而密钥明明是对的 | ❌ | **平台池没有可用凭证**（未发放/未激活/已吊销/用错池）——与"密钥错"`40100` 刻意分开 |
| 调用日志里一次 5xx 出现多条 OUT | ❌ | **每次 HTTP 尝试各一条**，便于逐次排查（长重试由状态机驱动） |
| 用「测试接口」测不出鉴权 | ❌ | 它**直调引擎、不过网关**；鉴权要调**平台对外路径** |
| 「模拟回调」在 `ENFORCED` 下仍可用 | ❌ | 平台自调带**内部令牌**豁免（仍写审计，`PLATFORM_SELF`） |
| 冷启动瞬间换 token 被打了两三次 | ❌ | 已知限制（TTL 内不再重复；真 single-flight 记 P2） |
| 云厂商签名离线**无法**确认云端是否接受 | ❌ | 需要供应商账号；离线只能核对"头与结构"，华为已用官方示例逐字节回归 |
| iPad/其他设备上 `X-Client-Id` 报 `40107` | ❌ | `require_client_id=1` 档下主体必须可识别；开放集请关掉该开关 |
| 用 `127.0.0.1` 与 `localhost` 打开前端表现不同 | ❌ | CORS 按 Origin 放行（已支持本机回环任意端口，但两者仍是不同 Origin） |
